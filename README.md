# Instacart Product Analytics Platform

End-to-end analytics engineering project using:

- Python
- DuckDB
- dbt
- Power BI
- GitHub Actions

## Business Goals

- Monthly Recurring Revenue (MRR)
- Annual Recurring Revenue (ARR)
- Churn Analysis
- Net Revenue Retention (NRR)
- Customer Lifetime Value (LTV)

## Architecture

Raw Data
→ Python
→ DuckDB
→ dbt
→ Power BI
